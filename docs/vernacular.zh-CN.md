# 生活概念层:小白的零术语创作

## 0. 规范表述(owner 原话)

> 严格按照第一性原理，深入调研现有传统及ai动画软件各种工具、概念，从0规划mo2d，最终愿景是，小白用户不用理解各种专业术语，仅凭生活常见基础概念结合ai就能制作调整播放交互动画。且额外学习成本做到最少，可控性熟悉度最高。

2026-11-17 记录为会话目标;本文档将其具体化。调研半边在 [landscape.zh-CN.md](landscape.zh-CN.md)(发现 F1–F13,下文引用记作 F*)。

## 1. 第一性原理定义

- **小白(novice)**:从未用过动画/设计软件、也不打算学其词汇的用户。不是"通往专业路上的初学者"——设计目标是可以永远停留在此状态的人。
- **额外学习成本** = 用户必须掌握的、*不属于*日常生活的概念数(关键帧、缓动、层级、状态机……)。**将它最小化意味着小白界面引入零个新概念**——界面上的每个词都是用户已经拥有的词(F2:术语而非概念,才是新手税)。
- **可控性** = 系统产出的每个结果中,能通过*直接、局部动作*(抓住这里、拖过去、说"慢一点")到达、且不推翻其他任何部分的结果占比。其反面就是生成视频的死胡同(landscape §3.6:改一条手臂→全部重生成)。
- **熟悉度** = 交互行为符合日常物理物性的占比(东西会落下、弹簧会晃、重的东西启动慢、没被再碰就一直保持原样)。日常物理作为默认行为。

这三者**可度量**,§6 把它们变成验收门——与仓库对确定性和吞吐量已有的纪律相同。

## 2. 生活概念字典(生活词→引擎编译)

这一层的产品就是这个字典:**用户说生活,AI 编译到命令协议。** 每条编译都落在既有内核词汇里——轨道线/节点/段缓动(line-model N4)、标准关系库的关系([relations.zh-CN.md](relations.zh-CN.md) §1)、参数、控制棒即线([ai-interaction.zh-CN.md](ai-interaction.zh-CN.md) §3)。标 ⓓ 的是调研时的提案——**owner 已于
2026-11-17 确认**(respond 关系族、`oscillate`、step 插值、表演录制;落路线图 C7,契约见
[relations.zh-CN.md](relations.zh-CN.md) §1.2)——它们只扩展、绝不妨碍模型。

### 2.1 动作词(让它动)

| 生活词 | 用户意图 | mo2d 编译 | 替代(术语) |
|---|---|---|---|
| 拉 / 拽 | 用手挪动它 | `node.move` 命令(直接操纵) | transform |
| 走到 X | 移动到某处 | 舞台上画一条直线→位置的轨道;AI 定 tick+缓动 | motion path+补间 |
| 转圈 | 持续旋转 | 旋转的循环轨道 ⓓ(R3 oscillate/cycle) | loop 表达式 |
| 变大 / 变小 | 缩放变化 | 盒线缩放的轨道(N8) | scale 关键帧 |
| 弹 | 撞上去弹回来 | sim 关系(重力+地面碰撞)或弹跳缓动轨道(N9) | physics 预设 |
| 摆 / 晃 | 绕一点来回 | sim 关系(弹簧/钟摆),种子固定(N9) | spring 约束 |
| 飘 | 慢慢漂 | sim(浮力/风)或循环位置轨道 ⓓ | noise 修改器 |
| 呼吸 | 轻柔重复鼓缩 | 缩放轨道两个关键帧+柔和缓动+循环;或 `oscillate` 关系 ⓓ | 表达式/循环 |
| 跟着 | 贴着运动的东西 | bind / propagate 关系 | 父子级 / IK 目标 |
| 转向 | 朝向某点 | constraint(look-at)关系 | IK aim 约束 |
| 回来 | 把动作倒回去 | 反向轨道 / 弹回锚点(sim) | — |
| 停住 | 停 N 拍 | 轨道节点间距(曝光) | hold frames / exposure |
| 慢一点 / 快一点 | 改速率 | 拉伸轨道段跨度(一条命令) | time-remap |
| 优雅一点 / 更弹 | 改手感 | 换段缓动(AI 从小的命名手感集里挑) | easing 曲线 |
| 一边…一边… | 两个动作叠加 | 两条属性各一条轨道线——什么都不用特殊处理 | timeline 图层 |

| 生活词 | 用户意图 | mo2d 编译 | 替代 |
|---|---|---|---|
| 出现 / 消失 | 某刻可见性 | 可见度/不透明度参数关键帧(N7/N4) | opacity 关键帧 |

### 2.3 交互词(让它响应)

感知→决策→响应的最小模型(F11)。owner 已确认的映射(2026-11-17;[relations.zh-CN.md](relations.zh-CN.md) §1.2):

| 生活词 | 用户意图 | mo2d 编译 | 替代 |
|---|---|---|---|
| 点它 / 戳它 | 响应点击 | respond 关系:事件 `tap(目标线)`→动作 | listener+trigger 输入 |
| 悬停 / 移开 | 指针在它上面 | 手势线 `hoverIn`/`hoverOut` 边沿(相位 1/0)+ hover 事件的 respond | mouseenter/mouseleave 监听器 |
| 碰到 / 撞上 | 响应接触 | respond 关系:事件 `overlap(线A, 线B)` | 碰撞事件 |
| 按住 / 松开 | 按压两态 | 手势线:press/release 边沿物化为逐目标的手势时间线(im=3);`press` / `release` 事件的 respond 关系写一个开关参数 | boolean 输入 |
| 长按 / 按久一点 | 持续按着一段时间 | release respond 带 `minHold`(时长=press→release 事件对测距=手势线按下段的长度) | long-press 事件 |
| 一碰就跳 / 害羞地躲开 | 事件→动作 | respond→切换/启动轨道(AI 顺便写轨道) | 状态机+过渡 |
| 等一下再… | 延迟响应 | `time-point(t)` / `track-end(轨道)` 事件的 respond | exit time / delay |
| 动一下就停下 | 一次性行为 | 触发语义:发一次即复位 | trigger 输入 |

**安放之处**:事件是单 tick 的不可逆事实;**手势是时间线**——它的相位边沿物化为时间轴上的**只读参考泳道**(`gesture/<目标线>`,step im=3,路线图 C8),按下段的长度就是按了多久。respond 关系是从(事件×守卫,含时长)到参数写入/触发的函数——正是"关系即函数"([relations.zh-CN.md](relations.zh-CN.md) §1.2)。纯播放器确定性地求值 respond 关系(同事件→同行为)——离线播放交互不丢,能力即数据(vision 规则 3)。

### 2.4 流程词(拼起来)

| 生活词 | 用户意图 | mo2d 编译 | 替代 |
|---|---|---|---|
| 一遍又一遍 | 循环 | 轨道循环标志 / sim 稳态 | loop 播放区间 |
| 然后接着 | 顺序 | AI 在同一批轨道上排布先后跨度 | 场景/序列 |
| 先…再… | 次序 | 轨道跨度排布(+track-end 的 respond ⓓ) | 时间轴排序 |
| 照我做的做 | 示范 | ⓓ 表演录制:捕获手势→轨道关键帧(F6,Dreams Perform 先例[^dreams]) | motion sketch / 录制 |

### 2.5 求助词(跟 AI 说话)

| 生活词 | 用户意图 | mo2d 编译 |
|---|---|---|
| 让它挥手 | 意图 | AI 建绑定+轨道+命令,舞台上全部可查 |
| 照这个样子 | 参考输入 | AI 从图像派生线(derive 关系 / external-ref) |
| 它自己动它会动的部分 | 自动绑定 | AI 提案骨架折线+bind,亮一个一眼确认检查点(F7)[^mixamo][^animated-drawings] |
| 这样不对 | 反馈 | AI 改*同一批*线/关键帧——或用户亲手拖;两个通道落在同一个真值上 |

**字典纪律**:小白界面只允许这些词(≤ ~25 个词根)。每个新动词要么编译到既有词汇,要么论证一个新的预定义关系——字典是一份**预算**,像其他门一样受审。

## 3. 小白交互循环(六步)

提炼自 landscape §3.4/§3.6/F13——每个被信任的 AI 工具都长这样:

1. **什么都能进**——涂鸦、照片、儿童画,或一句话(Motiff/Animated Drawings 先例)。无需学习:输入就是用户手头已有的东西。
2. **用生活话说意图**——用户说要什么(字典 §2);不点名任何功能,也不需要点名。
3. **AI 提案;一眼确认**——结构推断(部件/关节/变形器)以普通线+bind 关系落地,在舞台上亮出来供一眼校正(Mixamo 标记先例[^mixamo])。检查点是建立信任的地方——也是整个循环唯一的停顿。
4. **它以真身落地**——生成的动作=轨道线+关键帧;生成的响应=respond 关系;生成的控件=线(ai-interaction §3)。没有烘焙,没有二等公民(Figma Make 先例)。此刻舞台就*会演*——展示即编辑,无模式切换。
5. **用手或用话调——同一个真值**——在舞台上拖节点/拉跨度,或说"更弹一点";改的是同一批关键帧。直接操纵与语言是一个通道对(ai-interaction §2),永不对立(Kling 的运动路径手势保留,其像素拒收)。
6. **确定性播放+可回退历史**——随处播放:字节级一致,不需要 AI(能力即数据);每个 AI 动作都是命令流里的一个检查点——撤销即逆命令(v0/Lovable 先例[^spline-ai],见 landscape 来源)。

## 4. 设计规则(学习成本↓,可控性与熟悉度↑)

1. **没有不可见的状态**(F3):凡影响画面的东西都显形在用户正在看的地方——叠加物是线,控件是线;什么都不藏在折叠面板里(也没有面板)。
2. **每功能一个原语**(F10):一种遮罩、一种复用、一种层级——内核已经是这样;*小白界面*不得重新繁殖同义词。
3. **万物同一条规则**(熟悉度):线+关系,像实物一样画/连;没有需要死记的特例。
4. **日常物理是默认**(熟悉度):没被拴住的东西会垂下或落下(sim),被打断的动作弹回(阻尼弹簧回落),有分量感的东西起得更慢——手感集用生活词命名(弹性/飘/沉/跟手)。
5. **生活词编译成可编辑曲线**(可控性):"弹"解析为弹跳缓动的轨道或 sim 种子——绝不解析成烤死的短片(Pika 的动词预设:留下当*界面*,拒收当*产物*)。
6. **AI 落原生,绝不烘焙**(可控性,F13):生成物=普通线/关键帧/关系;每个生成物都可手修("只改一条手臂"的测试必须永远通过)。
7. **非确定只住在选择点**(信任):当 AI 必须在多个合理结果里挑,它给出舞台预览供用户指(Spline 四预览模式[^spline-ai]);选定之后,播放永远确定。
8. **一切可撤销,每个 AI 动作一个检查点**(信任):命令流本来就是历史(ai-interaction §4);小白永远不怕说"换个方式重做"。
9. **专业名字可选,永不必需**(零术语):引擎可以出于好奇给出"这是关键帧 (keyframe)"的次级标签——没有任何门槛、按钮或教程要求它。用户可以一辈子不遇见这个词。
10. **按需渐进深度,而非按课程**(F4/F12):第一个可见结果是无时间的姿势(拖木偶/滑杆——Live2D 教训);用户说出时间词时时间才进场;交互词最后来。每级都交付一个能用的结果。

## 5. 无术语的渐进披露

| 级 | 用户看见 | 所需新概念 | 在跑的内核 |
|---|---|---|---|
| 0——舞台+说话 | 画面、聊天框、播放 | 0 | 命令 |
| 1——手 | 拖动部件;它跟着手;"回到原位"锚点 | 0 | bind/propagate+参数(无时间姿势,F12) |
| 2——动作 | "走到那边""弹一下""晃一晃" | 0 | 轨道+缓动+sim |
| 3——响应 | "点它就跳""按住不动就眨眼" | 0 | respond 关系 |
| 4——高阶(可选) | 手柄、轨道以线的形式可见、专业标签 | 自选 | 全内核 |

各级**不是模式**——一个舞台,一个真值;层级只决定*展示*多少结构。专家视图是可生成视图(vision §2 部件 6):专业者认得的那种"时间轴"由 AI 按需画成线(line-model §3.1:播放头/轨道视图)。

## 6. 验收门(小白测试集)

具体的、可运行的门;会话目标完成=这些门被编排为 demo 命令流(仓库惯例:每步交付可见物,经命令流验收)。

- **N1——十分钟第一个动画、零术语**(目标:制作):从未用过动画软件的用户把一张涂鸦变成会挥手的角色:输入→确认绑定(一眼)→"让它挥挥手"→播放。度量:全程无专业术语出现;用户用到的概念 ≤ 字典 §2.5。先例:Animated Drawings 在儿童画上可用[^animated-drawings]。
- **N2——只改一条手臂**(目标:调整,可控性探针):在成品动画上,用户精确改变一条肢体的运动——用拖的,或说清是哪条;其余 95% 纹丝不动。唯一路径是全部重生成即失败(生成视频死胡同)。
- **N3——无代码无 AI 的交互**(目标:播放交互):"点它就跳一下"在纯离线播放器里可演——respond 关系确定性求值,无 AI,无脚本(能力即数据,vision 规则 3)。
- **N4——信任**:同一文档+同一命令流(含 AI 动作)重放字节一致;每个 AI 动作可经逆命令撤销。由既有确定性门覆盖,扩展到 respond 关系。
- **N5——概念预算**:小白界面全部(界面文案、AI 回复、面向小白的文档)只用 ≤ ~25 个生活词根(字典 §2),零专业术语必需。像冻结哈希门一样审计:黑话漏进小白界面即回归。
